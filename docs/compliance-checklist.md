# 合规检查清单

## 概述

本清单确保语言学习平台符合版权法、数据隐私和内容政策。

---

## 版权合规

### ✅ 内容来源验证

- [ ] 所有Media记录必须包含`complianceNotes`字段
- [ ] 每个Clip必须关联到已验证的Media
- [ ] `sourceType`字段正确标记：
  - [ ] `embed` - 使用官方嵌入代码
  - [ ] `external_redirect` - 仅存储链接
  - [ ] `self_hosted` - 附有版权证明文件

### ✅ 嵌入策略矩阵

| 平台 | embedPolicy.allowed | embedPolicy.provider | 备注 |
|------|---------------------|----------------------|------|
| YouTube | ✅ true | youtube | 使用官方embed API |
| Vimeo | ✅ true | vimeo | 需检查视频隐私设置 |
| Bilibili | ✅ true | bilibili | 仅限公开视频 |
| Netflix | ❌ false | - | 仅external_redirect |
| 自制内容 | ✅ true | self_hosted | 需上传版权声明 |

### ✅ 禁止操作

- ❌ **禁止下载和重新上传**第三方视频
- ❌ **禁止绕过**平台的地域限制
- ❌ **禁止去除**水印或署名
- ❌ **禁止修改**原始字幕时间戳（仅允许提取片段）

### ✅ 每日审计任务

运行自动化脚本检查：

```sql
-- 检查无合规说明的媒体
SELECT id, title FROM Media WHERE complianceNotes IS NULL OR complianceNotes = '';

-- 检查self_hosted但无embedPolicy的记录
SELECT id, title FROM Media 
WHERE sourceType = 'self_hosted' 
AND (embedPolicy IS NULL OR embedPolicy->>'allowed' != 'true');

-- 检查未授权的平台
SELECT DISTINCT platform FROM Media 
WHERE platform NOT IN ('YouTube', 'Vimeo', 'Bilibili', 'Self-hosted');
```

## 数据隐私（GDPR & CCPA）

### ✅ 用户数据最小化

- [ ] 仅收集必要的用户信息（email、学习进度）
- [ ] ShadowRecord表中的音频数据**匿名化**：
  - [ ] 不存储原始音频文件（仅波形统计）
  - [ ] waveformStats不包含可识别信息
- [ ] AnalyticsEvent表允许`userId`为NULL（匿名追踪）

### ✅ 用户权利

实现以下API端点：

- [ ] **访问权** - `GET /user/me/data-export` 导出所有个人数据（JSON格式）
- [ ] **删除权** - `DELETE /user/me/account` 删除账户及关联数据
- [ ] **更正权** - `PATCH /user/me` 更新个人信息
- [ ] **数据可携带性** - 导出数据为标准格式

### ✅ Cookie与追踪

- [ ] Cookie横幅（首次访问显示）
- [ ] 分析Cookie需用户同意
- [ ] 功能Cookie（会话）默认启用
- [ ] Cookie策略页面：`/privacy/cookies`

### ✅ 数据保留策略

| 数据类型 | 保留期限 | 清理方式 |
|----------|----------|----------|
| 用户账户 | 永久（活跃） | 用户主动删除 |
| 已删除账户 | 30天缓冲期 | 完全清除 |
| AnalyticsEvent | 90天 | 归档或删除 |
| ShadowRecord | 永久（匿名） | 不删除 |
| ReviewCard | 用户账户期间 | 随账户删除 |

### ✅ 第三方数据共享

- [ ] 隐私政策列出所有第三方服务：
  - [ ] OpenAI（向量生成）- 不发送用户个人信息
  - [ ] 云存储（S3/GCS）- 加密存储
  - [ ] 分析服务（可选）- 匿名化数据
- [ ] 数据处理协议（DPA）已签署

## 版权声明页面

### ✅ 必备内容

位置：`/legal/copyright`

**包含**：
1. **归属声明**：
   - 所有媒体内容版权归原作者所有
   - 本平台仅作为学习索引工具
   - 嵌入内容来自官方渠道

2. **免责声明**：
   - 本平台不托管未授权内容
   - 用户提交内容需符合政策
   - 我们保留删除违规内容的权利

3. **DMCA政策**：
   - 版权所有者联系方式：`dmca@example.com`
   - 投诉处理流程：24小时内响应
   - 反通知程序

4. **合理使用**：
   - 教育目的使用（Fair Use/Fair Dealing）
   - 片段短小（3-30秒）
   - 不影响原作品市场价值

## DMCA流程

### 收到侵权通知后

1. **24小时内**：
   - [ ] 记录投诉（ticket系统）
   - [ ] 通知相关审核员
   - [ ] 临时下线涉事内容

2. **48小时内**：
   - [ ] 审查投诉有效性
   - [ ] 联系内容提交者（如适用）
   - [ ] 决定：移除/恢复/修改

3. **7天内**：
   - [ ] 正式回复版权所有者
   - [ ] 记录处理结果到数据库
   - [ ] 更新合规日志

### 反通知流程

如果内容提交者提出反通知：

1. 提交者声明内容合法（宣誓书）
2. 转发反通知给原投诉方
3. 10-14个工作日后恢复内容（如无法律行动）
